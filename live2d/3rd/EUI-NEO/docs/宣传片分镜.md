# EUI-NEO 宣传片分镜

宣传片由 `apps/promo/app.cpp` 实现，播放时长 90 秒，结束后保持品牌片尾 3 秒。
音乐使用 `assets/music/Les Gordon - IKB (Audio).mp3`，播放期间以
`eui::audio::Player::positionSeconds()` 为唯一时间源。

## 视觉与资源

- 主画面采用浅色背景、黑色标题和框架原生控件；片尾使用黑色背景。
- 控件使用 `components::theme::light()` 和 `components::theme::dark()`，主题切换与音乐时间同步。
- 转场结合位移、缩放、旋转、透视与透明度；图表和轮播使用确定性的连续时间函数。
- Windows 字体配置为 `C:/Windows/Fonts/msyhbd.ttc`。部署到其他系统时需配置可用字体。
- 品牌图标来自 `assets/icon.png` 和 `assets/icon.svg`，Workshop 插画来自 `assets/Hard drive-rafiki.svg`。
- 画廊直接读取 `docs/pic/1.jpg` 至 `docs/pic/4.jpg` 以及 `示例1.jpg`、`示例2.jpg`，不复制为应用资源。

## 场景实现

`compose()` 按音频时间计算场景透明度，仅组合处于可见区间的场景。相邻场景在边界处交叠，
动画使用连续的位移、旋转和缩放，避免切换时出现位置突变。

- 开场的 `U` 和 `I.` 使用相同位移，保持字母组整体离场。
- 控件主题按区域设置相位差，颜色与卡片运动同步变化。
- `dataScene()` 组合三个图表和数据表；数据用于演示，不是运行时性能采样结果。
- 平台分支线连接各窗口的视觉中心，使脉冲路径与窗口位置一致。
- SVG 文件通过 `ui.image().source(...)` 加载；`ui.svg().source(...)` 接收内联 SVG 标记。
- 画廊通过浮点轮播进度控制相邻图片的位置、深度、缩放和透明度。

`galleryResourcePath()` 依次使用原始路径、`../` 和 `../../` 前缀调用
`resolveResourcePath()`，以支持从仓库及构建目录启动。独立分发宣传片程序时，
需要提供相应图片资源和可解析路径；图片不属于默认 `assets/` 目录。

## 播放状态

`PromoState` 持有音频播放器、播放状态、片尾计时和控件状态。

- 点击播放后检查音频加载和 `Player::play()` 的返回值；失败时保留待机界面并显示错误。
- 播放期间根据音频游标更新画面，不使用独立计时器推进分镜。
- 音频结束或游标达到 90 秒时停止播放器，并进入 3 秒片尾保持阶段。
- 只有播放和片尾保持阶段注册 `onFrame`；待机与重播界面使用事件驱动更新。
- 片尾计时结束后移除帧回调，避免静止界面持续重绘。

音频 API 的生命周期、错误处理和路径解析见 [音频](audio.md)。
